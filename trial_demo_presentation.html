Project Idea

Research Objective and Core Questions

Main objective

  • Analyze how GDP is associated with demographic and macroeconomic indicators.
  • Forecast key variables over time for each country.
  • Translate analytical outputs into an interactive dashboard for exploration and decision support.

Research questions

  • How do Population and Life Expectancy relate to GDP?
  • Do Inflation, Unemployment, Internet usage, and global shocks improve GDP prediction?
  • Which time-series model is best for GDP, Population, and Life Expectancy?
Focus: interpretation + forecasting + practical presentation 2 / 9

Feature Engineering

Global Event Dummies and Modeling Inputs

Global event dummies included

  • Asian Financial Crisis (1997–1998)
  • Global Financial Crisis (2008–2009)
  • COVID shock (2020)
  • COVID rebound (2021)
  • Ukraine / energy shock (2022–2024)

Why they matter

  • Capture common macro shocks across many countries.
  • Improve interpretation of GDP changes beyond country-specific indicators.
  • Support the “global events affecting GDP” requirement from the lecturer.
Event timing was engineered manually from domain knowledge and official sources 4 / 9

Interpretation

Time-series model selection has been completed for all three variables using a rolling 10-year window. This phase provides the forecasting foundation before moving into the main GDP prediction models.

Backtest Best vs Future Forecast Model

  • Best backtest model is kept for evaluation and reporting.
  • Live future forecast demo uses GDP → ARIMA, Life Expectancy → Holt, Population → LogHolt.
  • This avoids flat forecast paths and produces more interpretable future scenarios in the dashboard.

Main GDP Models

Three GDP Prediction Specifications

Model 1

Baseline GDP Model

GDP ~ Population + Life Expectancy

Purpose: establish the simplest interpretable benchmark.

Model 2

Extended GDP Model

GDP ~ Population + Life Expectancy + Inflation + Unemployment + Internet

Purpose: test whether macro and digital indicators improve prediction.

Model 3

Full GDP Model

GDP ~ Population + Life Expectancy + Inflation + Unemployment + Internet + Event Dummies + Region Effects + Year Effects

Purpose: capture structural and global-shock effects.

Current status

  • Framework and merged data are ready.
  • Next modeling step is consistent train/test evaluation on the same sample.
  • Final comparison will use MAE, RMSE, MAPE, and R².

Scenario 4

Interactive Streamlit Dashboard

Implemented dashboard elements

  • Multi-indicator overview for GDP, Population, and Life Expectancy
  • Indicator trends by country and region
  • Country / region comparison
  • Backtest comparison of 3 candidate models per indicator
  • Best overall model and best for selected country
  • Live target-year forecast with rolling 10-year window

Why Streamlit

  • Fast to build and easy to demo
  • Integrates directly with pandas and Plotly
  • Emphasizes interpretability and usability
  • Lets the project move from notebook results to an interactive presentation layer quickly

Current app file

app.py is placed in the project root and now combines panel overview, model comparison, backtest exploration, and live forecasting for the demo.

Suggested live demo flow

  • Show the merged panel and engineered variables.
  • Open Time-Series Models and compare 3 models for one country.
  • Highlight best overall model and best for the selected country.
  • Move to Forecast Explorer and enter a target future year.
